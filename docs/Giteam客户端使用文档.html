01 / 快速开始

准备好桌面端安装包、一个本地 Git 仓库，以及内部模型平台发放的 API Key。

下载 Giteam 桌面端

根据你的电脑系统选择对应安装包。下载完成后双击安装即可。

macOS · Apple 芯片 适用于 Apple Silicon（ARM64） Windows Windows 安装程序（64 位） Ubuntu / Debian 适用于 Debian / Ubuntu（64 位）
macOS 安装提示
如果打开应用时提示“文件已损坏”或无法验证开发者，请先打开“终端”，执行下面的命令。命令中的文件名需要替换为你实际下载的文件名。 sudo xattr -dr com.apple.quarantine ~/Downloads/Giteam_0.2.10_aarch64.dmg 然后重新打开安装包。如果安装包不在“下载”文件夹，请将路径改为实际位置。
版本更新：安装包为初始版本。安装后请在「设置 → 关于」中点击“检查更新”，即可升级到包含自动化任务、项目分享、记忆图谱等功能的最新版本。

打开项目

在首页导入本地项目文件夹。建议选择项目根目录，方便 Giteam 识别完整代码。

连接模型

在设置的“模型”中添加内部模型平台，保存后选择一个可用模型。

开始任务

在底部输入框说明目标，点击发送。涉及修改或命令时，先阅读授权提示。

启动 Giteam 桌面端
等待首页加载完成。
导入项目
选择本地仓库文件夹，并在左侧确认项目名称和路径正确。
新建会话
每个相对独立的工作建议使用一个会话，便于回看和整理。
发送第一条消息
说清楚目标、范围，以及是否允许修改文件。
推荐说法：“请检查 src/login.ts 的登录失败处理，只给出建议，不要修改文件。”

02 / 内部模型配置

API Key 需要先向内部模型平台申请。申请完成后，在 Giteam 的模型设置中填写以下信息。

固定信息：供应商名称为 INDEMIND；地址为 http://192.168.50.77:3921/v1，地址不会变化；接口类型选择 OpenAI Completions。
申请 API Key
按公司内部流程向内部模型平台提交申请。不要自行编写，也不要使用他人的密钥。
进入模型设置
点击“设置”，打开“模型”。找到 OpenAI 兼容端点，或使用“新增自定义”。
填写连接信息
供应商名称填 INDEMIND；API Key 粘贴申请到的密钥；地址填 http://192.168.50.77:3921/v1。
选择接口并保存
接口类型选择 OpenAI Completions，点击“连接”或“保存连接”。显示“已连接”后，再选择模型。

配置检查

  • 供应商名称：INDEMIND
  • API Key：内部平台申请的有效密钥
  • Base URL：http://192.168.50.77:3921/v1
  • 接口：OpenAI Completions

安全提醒

  • 粘贴 Key 后检查是否带有空格或换行。
  • 不要将 Key 放入代码、截图、群聊或 Git。
  • 怀疑泄露时，立即联系平台管理员重置。

03 / 日常工作

常用顺序是：选项目 → 新会话 → 描述目标 → 检查结果。

先讨论，再执行

只想了解方案时使用 Plan；确认方案后切换 Build，让 AI 执行修改或命令。

始终检查变更

任务完成后打开“变更 / Changes”，查看具体差异，确认无误后再提交代码。

运行中也能继续提问

AI 正在工作时可以直接发送新消息，消息会排队等待；当前回复完成后自动继续处理，不需要反复等待或重发。

减少来回确认

对于明显的下一步，AI 会直接执行，不再反复询问“要继续吗”；涉及风险的操作仍会先请你审批。

一个清楚的任务描述

目标：给登录页增加手机号格式校验
范围：只修改 src/pages/Login.tsx 和对应测试
要求：先说明计划；完成后运行相关测试并总结改动
授权提示：当 AI 需要修改文件、运行命令或访问项目内容时，请先看清操作内容和影响范围。不确定时可以拒绝，并让 AI 先解释。

04 / 自动化任务

让 Giteam 按计划自动执行重复性工作，例如每天早上检查代码、定期生成周报。任务由本机的 AI 在后台静默完成。

打开自动化
在左侧栏切换到「自动化」视图，点击创建新任务。
绑定项目和目标
选择一个已导入的项目，写清楚要自动完成的目标；可以每次新建会话，也可以固定使用某个已有会话。
设置执行计划
支持每天、工作日、每周、按间隔或自定义时间；还可以为任务单独指定模型、推理强度和通知级别。
查看运行结果
任务详情中保留运行历史。运行完成后会显示未读蓝点，打开详情即标记已读；也可以随时手动「立即运行」或暂停任务。
注意：自动化任务由本机执行，需要保持 Giteam 处于运行状态；如果目标会话正忙，本次执行会自动跳过并记录在历史中。

钉钉通知

任务可以配置钉钉群机器人通知：填入机器人的 Webhook 地址，可选填写加签 Secret，保存前用「测试发送」确认群里有收到。任务结束后只推送最终摘要（Markdown 格式，过长时自动分段），不会刷屏工具调用过程。通知渠道可在「系统通知 / 钉钉 / 不通知」之间切换。

05 / 项目分享

把项目连同 AI 会话记录、项目记忆一起打包成分享链接，发给同事后对方可以一键导入，直接接着上下文继续工作。

分享项目

在项目列表中右键项目，选择「分享项目…」。Giteam 会将代码、AI 会话、记忆和附件打包上传，生成分享链接；导出时会自动脱敏 API Key、Token、私钥等敏感信息。

导入分享

在「添加项目」向导中选择远程导入，粘贴分享链接即可。导入过程有进度条，可以随时取消；也可以把分享内容合并到本地已有的仓库。

安全提醒：获得链接的人即可下载项目内容。分享前请确认仓库可以对外；不再需要时请及时撤销分享。

06 / 仓库记忆图谱

Giteam 会从历史会话中自动提炼项目的决策、文件修改和踩过的坑，形成可视化的记忆图谱，让 AI 在新会话中也能“记得”之前发生的事。

自动积累

每次会话结束后，关键决策、涉及的文件和遇到的错误会被自动记录，无需手动整理。

跨会话回忆

开始新任务时，AI 会自动检索相关历史，减少重复解释背景，也避免重蹈之前的错误。

图谱浏览

打开记忆图谱面板，可以缩放查看节点关系、按时间范围筛选，并快速定位到当前会话相关的内容。

07 / 常用设置

工作区

  • 文件树：浏览项目文件并查看内容。
  • 变更：查看本次任务修改的文件和差异。
  • 分支：在左侧栏搜索、切换或新建分支，查看代码状态。
  • 终端：在项目目录运行命令。

应用设置

  • 通用：语言、主题、界面缩放和代码字号。
  • 通知 / 声音：控制完成、授权和错误提醒。
  • 模型：连接供应商、选择模型。
  • 关于：查看版本并检查更新。

移动端连接

如果已启用移动端控制，可在“设置 → 移动端控制”开启服务，使用连接地址、配对码或二维码连接手机。建议使用配对码授权，用完后关闭服务。

更新应用

在“设置 → 关于”中点击“检查更新”。安装更新前，请先保存未提交的代码修改。

08 / 问题排查

连接模型失败

确认电脑可以访问 192.168.50.77，API Key 有效，地址完整包含 /v1，并且没有多余空格。仍失败时联系内部模型平台管理员。

已连接但没有模型

点击刷新。如果仍为空，可能是 Key 没有模型目录权限，或平台暂时没有返回模型。反馈时不要提供完整 API Key。

发送按钮不能用

先确认已选择项目和可用模型。没有模型时返回“设置 → 模型”完成连接。

不满意 AI 的修改

先不要提交代码。在“变更”中查看差异，可以继续说明需要调整的地方，也可以手动编辑或撤销。

自动化任务没有按时执行

确认 Giteam 桌面端保持运行、任务处于启用状态。如果到点时目标会话正忙，本次会自动跳过，可在运行历史中查看记录。

钉钉群收不到通知

在任务的钉钉设置中使用「测试发送」检查 Webhook 地址是否正确；如果机器人开启了加签，确认 Secret 填写一致且没有多余空格。

开始前的确认

项目已打开

左侧显示正确的仓库名称和路径。

模型已连接

模型设置显示“已连接”，并且已选中模型。

结果已检查

重要修改已在“变更”中确认。
