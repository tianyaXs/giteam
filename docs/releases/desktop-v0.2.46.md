# Giteam Desktop v0.2.46

发布标签：`desktop-v0.2.46`

## 项目分享导入体验

- 远程导入增加**进度条**：阶段文案、百分比，下载时显示已传/总量
- 导入过程中可**取消**（取消按钮 / 关闭对话框），中断下载与 `git clone`
- 去掉「将导入到 …」重复预览文案
- 跨平台路径比较（Windows `\` / 大小写）选中刚导入项目（延续 0.2.45）

## Agent 与会话

- `list_sessions` 对「模型缺失 / 无 API Key」等 restore 失败做**冷却缓存**
- 同一错误只打一次日志，5 分钟内不再反复尝试 Pi SDK restore，避免控制台刷屏
- 保存 API Key / 自定义供应商 / 连接兼容端点后自动清空缓存，便于修好凭据后恢复

## 自动化

- 「创建」按钮去掉多余下拉箭头（仅文字）

## 说明

功能基线同 [v0.2.44](./desktop-v0.2.44.md) / [v0.2.45](./desktop-v0.2.45.md)（自动化、项目分享、Agent 对账等）。

CLI 请使用 **v0.1.53** 及以上以配套分享命令行。

git tag desktop-v0.2.46
