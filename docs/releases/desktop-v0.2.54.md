# Giteam Desktop v0.2.54

发布标签：`desktop-v0.2.54`

## 输入框与模型配置

- 模型 / 推理等级合并为单个 DSH 式摘要入口：`模型名 等级 ˄`，点开是「模型 ›」「推理等级 ›」两行子菜单
- 「自动接受权限」提到一级菜单，点开关直接切换
- 菜单从输入框上方弹出，不再贴窗口底边；子菜单复用官方 DropdownMenu / ModelSelector 基线
- 无可用模型时点选择器直接进模型设置页；`/model` 斜杠命令同样直达设置
- 模型分组标题显示用户可读的供应商名（不再出现 `openai-compatible.*` 内部 id）

## 推理等级

- 取消「自动」档：推理模型显式选择 关闭 / 极低 / 低 / 中 / 高 / 极高（支持 xhigh 的模型多一档）
- 默认档改为「关闭」，对齐 DeepSeek 深度思考默认关闭的交互；旧存储里的 auto/空值统一归一化为关闭
- 发送给引擎的档位始终显式，自动化任务同样写入明确档位

## 消息流

- 流式输出不再闪横向滚动条（Virtuoso 官方 Item 协议做横向裁剪）
- 滚到顶加载历史后往回滚动不再卡住；点击「拉到最新」一次到位
- 停止按钮方块尺寸与配色对齐官方实现

## 发布

```bash
git tag desktop-v0.2.54 && git push origin desktop-v0.2.54
```
