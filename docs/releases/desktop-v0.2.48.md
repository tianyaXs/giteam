# Giteam Desktop v0.2.48

发布标签：`desktop-v0.2.48`

## 自动化 · 钉钉通知

- 默认以 **markdown** 推送最终摘要（标题 `### 任务：…`）；发送失败自动回退 **text**
- 对钉钉弱支持语法做清洗：代码围栏改为引用、表格行改为列表；表行较多时直接走 text
- 超长正文按约 18KB 分段发送，标题带 `（i/n）`
- 通知正文使用完整摘要；历史列表仍截断保存，避免库膨胀

## 其它

- 修复：分享导入对话框点击空白处会意外关闭

## 说明

- 功能基线同 [v0.2.47](./desktop-v0.2.47.md)

git tag desktop-v0.2.48
git push origin desktop-v0.2.48
