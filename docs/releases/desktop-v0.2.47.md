# Giteam Desktop v0.2.47

发布标签：`desktop-v0.2.47`

## 自动化 · 钉钉通知

- 自动化任务可按任务配置**钉钉群机器人**通知（Webhook + 可选加签 Secret）
- 通知渠道：系统通知 / 钉钉 / 不通知；钉钉支持表单内「测试发送」
- 任务结束后只推送**最终摘要**（不含工具调用过程）
- 通知标题统一为「任务：…」
- 立即运行前自动保存当前表单，避免配置未落库导致发不出
- 修复：钉钉渠道保存后被误显示成系统通知（序列化命名）
- 修复：成功运行不发钉钉、加签 Secret 误用全局配置、async 内阻塞 HTTP
- 修复：残留 `running` 状态导致「task already running」无法立即运行

## 自动化 · 体验

- 列表运行状态与会话执行同步：开始时标记 running，结束后才清除
- 创建成功后收起表单，回到任务列表
- 去掉详情页右上角关闭按钮，避免与右侧边栏切换冲突；可用底部「取消」
- 选中态 / 运行中状态改用主题语义色，深色模式更清晰
- 顶部保留透明拖拽带，不拆独立小字号标题栏

## 布局

- 拖拽侧栏分隔线时禁止整页文本选中，避免左右栏被拖蓝

## 说明

- 本期钉钉以**任务级出站通知**为主；群 @ 反向触发（Gateway Outgoing）代码已预留，产品侧暂未开放设置入口
- 功能基线同 [v0.2.46](./desktop-v0.2.46.md)
